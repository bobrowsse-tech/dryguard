# @dryguard/lsp-server

Language server for DryGuard. It publishes duplicate-code diagnostics and code actions for any editor that speaks LSP.

```bash
npx -y @dryguard/lsp-server
```

The VS Code extension, the JetBrains plugin, and the Neovim config all launch this server.

See the [DryGuard repository](https://github.com/bobrowsse-tech/dryguard#readme).
