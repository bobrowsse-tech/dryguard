# @dryguard/mcp-server

MCP server that lets an AI coding agent index a workspace and check a proposed function for duplicates before writing it.

```bash
npx -y @dryguard/mcp-server
```

Tools: `index_workspace`, `check_similarity`, `get_refactor_suggestion`.

See the [DryGuard repository](https://github.com/bobrowsse-tech/dryguard#readme) for editor and CI setup.
