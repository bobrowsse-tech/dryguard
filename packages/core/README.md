# @dryguard/core

Structural duplicate-code detection for DryGuard: AST fingerprinting, structural and semantic similarity, config, baselines, and the incremental cache.

This package is the engine. Editor and agent integrations live in `@dryguard/mcp-server`, `@dryguard/lsp-server`, and `@dryguard/cli`.

See the [DryGuard repository](https://github.com/bobrowsse-tech/dryguard#readme) for setup and usage.
