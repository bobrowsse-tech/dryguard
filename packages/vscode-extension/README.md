# DryGuard

DryGuard flags structurally duplicate functions — written by you or by an AI coding agent — as editor diagnostics, before they land.

Install this extension for VS Code, Cursor, Windsurf, or VSCodium. It starts the DryGuard language server and adds an AI-assisted "merge this duplicate" quick fix.

- **Re-index** from the command palette: `DryGuard: Re-index Workspace`
- **Threshold** and **enable** live in Settings under `dryguard`

CI and agent setup are documented in the [DryGuard repository](https://github.com/bobrowsse-tech/dryguard#readme).
